# ReliefRoute

ReliefRoute is a student Flutter project for browsing medicines, viewing sample
orders, and recording reminders. The project also contains a small Spring Boot
backend and a MySQL database script.

## Folders

- `reliefroute/` - main Flutter application
- `backend/` - Spring Boot REST API
- `reliefroute/database/mysql/` - MySQL tables and sample medicines
- `reliefroute/firebase/` - Firebase rules and indexes

## Main technologies

- Flutter and Dart
- Java 17 and Spring Boot
- MySQL
- Firebase Authentication and Firestore

This is a learning project. Some screens still use sample data and are clearly
marked in the application.
